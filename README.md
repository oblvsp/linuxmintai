# Linux Mint AI

Гибридный AI-воркспейс для Linux Mint с облачным маршрутом через OpenRouter и локальным резервным маршрутом через Ollama.

## Целевая конфигурация

- **Основной маршрут:** бесплатные модели OpenRouter с поддержкой инструментов через [ollama-free-model-proxy](https://github.com/aljazceru/ollama-free-model-proxy).
- **Резервный маршрут:** локальная `crewai-qwen3-8b` через Ollama и `bastion-broker`; при ошибке облачного вызова предполагается автоматический fallback.
- **Железо:** Intel Core i5-8400, 32 ГБ RAM, NVIDIA RTX 2070 SUPER с 8 ГБ VRAM. Объём VRAM — критическое ограничение для локальной модели.
- **Предполагаемые порты:** Ollama `11435`, bastion `11434`, OpenRouter proxy `11436` (чтобы порты не конфликтовали).

Вызовы должны показывать фактически выбранные модель и маршрут: `cloud:openrouter` или `local:ollama`. Пример конфигурации и пошаговый план находятся в [PROMPT.md](PROMPT.md).

## Важно: статус и проверка

Этот репозиторий содержит план настройки, а не отчёт о развёртывании. Наличие компонентов на конкретной машине не проверялось, установки и тестовый вызов CrewAI не выполнялись. Перед установкой следует выполнить предварительные проверки из `PROMPT.md`, пропускать уже установленные компоненты и сверять команды с актуальной документацией проектов.

## Безопасность и приватность

- Запросы через OpenRouter покидают локальную машину. Не передавайте туда секреты, личные данные или проприетарный код; для приватных задач используйте локальную модель.
- Не отключайте подтверждение опасных команд в Open Interpreter.
- Лимиты и доступность бесплатных моделей OpenRouter меняются; значения в промпте являются ориентировочными, а не гарантией.
- Храните API-ключи в окружении/менеджере секретов и не публикуйте их в репозитории.
