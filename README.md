# Linux Mint AI

Полностью приватный (local-only) AI-воркспейс для Linux Mint: CrewAI-агент системного администрирования на локальных моделях через Ollama, защищённый bastion-broker. Облачных маршрутов и API-ключей в архитектуре нет — ни один запрос не покидает машину.

Назначение ассистента — настройка и обслуживание ОС. Для написания кода используются внешние облачные модели (это осознанное разделение, см. [PROMPT.md](PROMPT.md), шаг 9).

## Архитектура

- **Ollama** — системный сервис на `127.0.0.1:11435` (loopback), `OLLAMA_MAX_LOADED_MODELS=1`, flash-attention, KV-кэш q8_0.
- **bastion-broker** — юнит пользователя на `127.0.0.1:11434`, прозрачный прокси к Ollama: VRAM-бюджет, очередь и serialization загрузки моделей на единственный GPU, телеметрия `/broker/status`.
- **Модели**: `crewai-qwen3-8b` (агентные задачи с инструментами, Q4_K_M, 5.4 GB, 100% GPU) и `qwen3.5:9b` (вопросы без инструментов).
- **CrewAI 1.15.x** в `~/ai-workspace/venv` (uv): `config_llm.py` (два объекта LLM + `describe_now()`), `bash_tool.py` (bash-инструмент с чёрным списком деструктивных команд), `agent_demo.py` (демо-агент).
- **Open Interpreter** — установлен (0.0.56), но **непригоден на этом железе**: его codex-движок отправляет системный промпт ~11 900 токенов, что требует контекст >8 GB VRAM в KV-кэше. Для агентных задач — CrewAI-агент. Подробности: PROMPT.md, шаг 8.
- **Железо:** Intel Core i5-8400, 32 ГБ RAM, RTX 2070 SUPER 8 ГБ VRAM. VRAM — критическое ограничение: на GPU помещается одна 8B-модель, переключение двух стоит ~20 с.

Порты: bastion `11434`, Ollama `11435`. Оба привязаны строго к 127.0.0.1.

## Установка

    git clone https://github.com/oblvsp/linuxmintai && cd linuxmintai
    ./install.sh

Скрипт идемпотентен: каждый блок пропускается, если компонент уже настроен; повторный запуск безопасен. Для привилегированных шагов нужны sudo или pkexec.

## Реальный статус

Архитектура не теоретическая: стек развёрнут и проверен в бою на целевой машине 2026-10-30 (демо-агент выполнял системные команды через BashTool, модель резидентна на GPU, `bastion --validate` — 0 failed). В [PROMPT.md](PROMPT.md) зафиксированы найденные при развёртывании подводные камни: опасные дефолты `bastion --init-config`, неработающий auto-detect VRAM в systemd user-сервисе, отсутствующий `ShellTool` в crewai-tools, недоступность домашнего каталога для сервиса `ollama` при импорте GGUF и другие.

## Безопасность и приватность

- Всё на loopback: проверять `ss -tlnp | grep -E ':1143[45]'` после каждой настройки.
- Не отключайте подтверждения опасных команд в Open Interpreter; чёрный список BashTool не ослаблять.
- Перед запуском агентов — OOM-защита: swap ≥16 GB, earlyoom (`-m 15 -s 60`), `vm.swappiness=10` (реальный инцидент с фризом задокументирован в PROMPT.md, шаг 2.5).
- Секретов в системе нет по определению; при тестовых запусках следите, чтобы агент не вывел в лог содержимое личных файлов.
