# PLAN.md — память проекта linuxmintai

Этот файл агент читает в начале каждого запуска. Держите его коротким: в промпт
уходит не больше 2500 символов.

## Стек
- Ollama 127.0.0.1:11435 → bastion 127.0.0.1:11434 → Open WebUI :3000, панель :11436.
- Одна модель qwen3.5:9b, контекст 24576, ~35 tok/s. Смена модели стоит 5–15 с.
- Агент: ~/ai-workspace/venv, CrewAI; инструменты bash, web_search и fetch_page.
- Поиск: SearXNG на 127.0.0.1:8888 — единственный канал наружу; остальное локально.

## Правила
- Все демоны слушают только 127.0.0.1. Новые порты — тоже.
- Root-действия только через pkexec: sudo без пароля нет.
- Диагностика до лечения; перед необратимым — остановиться и спросить.
- ~/Документы/HeadPhones — другой проект, его файлы не трогать.
- Опасные команды: rm -rf, mkfs, dd, fdisk, правка /etc без бэкапа.

## Текущий фокус
- Стек развёрнут и стабилен; идёт доработка агентных возможностей (память, гейт команд).
